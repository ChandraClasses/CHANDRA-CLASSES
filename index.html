Easy Step-by-Step Guide

Website & PDFs ko Free live karne ka tareeqa:

  1. 1. Code Save Karein: Is poore code ko apne computer/phone me index.html naam se save kar lein.
  2. 2. GitHub Account Banayein: github.com par jaakar free account banayein.
  3. 3. New Repository: New repository click karein, naam rakhein chandra-classes aur "Create repository" dabayein.
  4. 4. index.html Upload Karein: Upload files par click karke index.html file drag & drop karke upload kar dein.
  5. 5. PDF Kaise Upload Karein: Wahan Add file → Upload files par click karein aur apni PDF (jaise syllabus.pdf) upload kar dein. Website me PDF ka naam exact same hona chahiye!
  6. 6. Website Live Karein: Repository me Settings → Pages par jayein. Branch me main chun kar Save karein. 2 minute me aapki website lifetime free live ho jayegi!
